# 🌱 UnForest

> UnForest é um jogo educacional desenvolvido para ensinar crianças e adolescentes sobre as mudanças climáticas, seus impactos no planeta e a importância da preservação ambiental.

O projeto é desenvolvido como parte do Trabalho Interdisciplinar IV (TI4) e tem como base as ODS 4 - Educação de Qualidade e ODS 13 - Ação Contra a Mudança Global do Clima, utilizando elementos de **gamificação para tornar o aprendizado sobre sustentabilidade mais interativo e envolvente.**

## 🌎 Sobre o jogo

Em um futuro pós-apocalíptico, as consequências das mudanças climáticas transformaram completamente o planeta. Florestas foram destruídas, geleiras derreteram, cidades foram tomadas pela poluição, os oceanos foram contaminados pelo lixo e regiões inteiras sofreram com a seca.

Nesse cenário, o jogador assume a missão de salvar o planeta e restaurar as regiões afetadas pelas mudanças climáticas.

Para isso, o jogador deverá enfrentar diferentes desafios relacionados aos principais problemas ambientais presentes no mundo de UnForest.

## 🎮 Como funciona?

Ao iniciar o jogo, o jogador participa de um quiz conduzido por Inteligência Artificial. Com base nas respostas, o jogador poderá definir um Guardião, que guiará pela sua jornada.

Existem 5 Guardiões, cada um associado a uma das cinco fases do jogo:

- 🌳 Desmatamento nas florestas
- 🧊 Derretimento das geleiras
- 🏙️ Poluição nas cidades
- 🌊 Lixo nos oceanos
- ☀️ Seca no deserto

A escolha do Guardião também determina qual fase o jogador irá começar.

Em cada fase, o jogador deverá completar um desafio relacionado ao problema climático daquela região. Ao concluir o desafio, a área correspondente do mapa é restaurada, aproximando o jogador do objetivo final: ***salvar o planeta.***

## 🎯 Objetivo

O principal objetivo de UnForest é educar crianças e adolescentes sobre as mudanças climáticas de forma interativa e lúdica, apresentando seus impactos e incentivando a reflexão sobre a preservação do meio ambiente.

Durante a jornada, o jogador deverá:

- 🌍 Conhecer diferentes consequências das mudanças climáticas;
- 🧠 Aprender por meio de desafios e interação;
- 🎮 Resolver problemas relacionados a diferentes impactos ambientais;
- 🌱 Recuperar as regiões afetadas do mapa;
- 🤝 Desenvolver uma maior consciência sobre a preservação do planeta.

### 👧🧑 Público-alvo

O jogo é destinado principalmente a crianças e adolescentes de 8 a 15 anos.

### 🤝 ODS relacionadas

- ODS 4 — Educação de Qualidade

O projeto utiliza a gamificação como ferramenta educacional, buscando proporcionar uma experiência de aprendizagem interativa e acessível sobre questões ambientais.

- ODS 13 — Ação Contra a Mudança Global do Clima

O jogo aborda diferentes consequências das mudanças climáticas e busca conscientizar os jogadores sobre os impactos das ações humanas no planeta e a importância da preservação ambiental.

## 🚀 Como executar

> Antes de executar o projeto, é necessário ter o Flutter instalado e configurado no ambiente.

git clone https://github.com/zuimcode/Trabalho-Interdisciplinar-4---UnForest.git    
// Clone o repositório

cd .\UnForest\    
// Acesse a pasta do projeto

flutter pub get    
// Instale as dependências

flutter run -d chrome    
// O Flutter abrirá o UnForest no navegador Chrome.
